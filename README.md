# POD Atlas

POD-Atlas-Baslat.cmd ile çalıştır. Arama sonuçları ürünlerin fiyatını, fotoğrafını ve doğrudan ürün bağlantısını gösterir.

Güncel bağlantı kapsamı: BAGLANTI-DURUMU.md. Fiyat kontrolünün kapsamı ve kalan işler: FIYAT-KONTROLU.md.

121 firmanın tamamı bağlı değildir. Fiyat kontrolü bütünüyle tamamlanmış değildir. Doğrulanmayan veya koşullu bedeller incelemeye ayrılır.
